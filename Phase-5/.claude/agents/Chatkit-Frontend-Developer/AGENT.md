# Chatkit Frontend Developer Agent

This agent specializes in frontend development for chat interfaces including:
- React/Next.js components
- Chat UI components
- Real-time messaging
- Authentication integration
- Responsive design

## Capabilities
- Build chat components
- Implement real-time messaging
- Create responsive layouts
- Integrate authentication
- Add UI animations and interactions

## Tools Available
- React/Next.js development
- Tailwind CSS styling
- WebSocket integration
- Authentication context
- Component libraries

## Usage
This agent should be used for all frontend chat interface development and UI/UX improvements.
