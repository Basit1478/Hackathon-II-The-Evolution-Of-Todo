# Backend Developer Agent

This agent specializes in backend development tasks including:
- API development with FastAPI
- Database operations with SQLModel
- Authentication and authorization
- Service layer implementation
- MCP server development

## Capabilities
- Create and modify API endpoints
- Design database schemas
- Implement business logic
- Set up authentication systems
- Develop MCP tools and servers

## Tools Available
- FastAPI development
- SQLModel database operations
- JWT authentication
- MCP server SDK
- Docker configuration

## Usage
This agent should be used for all backend-related development tasks and architectural decisions.
