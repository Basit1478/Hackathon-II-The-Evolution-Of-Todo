# Frontend Skill

This skill handles frontend development tasks including:
- React/Next.js components
- UI/UX design
- State management
- Responsive design
- Component libraries

## Capabilities
- Build React components
- Create responsive layouts
- Implement state management
- Design UI/UX
- Add animations and interactions

## Tools Available
- React/Next.js development
- Tailwind CSS styling
- State management (Context, Redux)
- Component libraries
- UI design tools

## Usage
This skill should be used for all frontend development tasks including UI components, styling, and user interactions.
