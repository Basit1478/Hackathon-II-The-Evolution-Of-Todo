# DevOps Skill

This skill handles DevOps and infrastructure tasks including:
- Docker configuration
- Kubernetes deployment
- Helm charts
- CI/CD pipelines
- Infrastructure as code

## Capabilities
- Create Dockerfiles and docker-compose
- Set up Kubernetes manifests
- Create Helm charts
- Configure CI/CD pipelines
- Manage infrastructure

## Tools Available
- Docker configuration
- Kubernetes manifests
- Helm charts
- CI/CD pipeline configuration
- Infrastructure as code tools

## Usage
This skill should be used for all DevOps and infrastructure-related tasks including containerization, deployment, and infrastructure management.
