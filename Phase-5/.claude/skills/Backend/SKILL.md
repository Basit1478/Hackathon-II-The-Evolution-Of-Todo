# Backend Skill

This skill handles backend development tasks including:
- API development with FastAPI
- Database operations with SQLModel
- Service layer implementation
- Error handling
- Performance optimization

## Capabilities
- Create and modify API endpoints
- Design database schemas
- Implement business logic
- Set up middleware
- Optimize database queries

## Tools Available
- FastAPI development
- SQLModel ORM
- Database migrations
- Service patterns
- Error handling utilities

## Usage
This skill should be used for all backend development tasks that don't fall under specialized categories like authentication or MCP servers.
