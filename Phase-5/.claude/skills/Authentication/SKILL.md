# Authentication Skill

This skill handles authentication-related development tasks including:
- User authentication flows
- JWT token management
- Password hashing
- Session management
- OAuth integration

- Implement authentication endpoints
- Create authentication middleware
- Manage user sessions
- Handle password security
- Integrate third-party auth providers

## Tools Available
- FastAPI authentication
- JWT token management
- Password hashing utilities
- Session storage
- OAuth libraries

## Usage
This skill should be used for all authentication-related development tasks and security implementations.
