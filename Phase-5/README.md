# Phase-5 Directory Structure

This is the main directory for the Phase 5 project containing all the application components.

## Directory Structure
- `.claude/` - AI agent configurations and skill definitions
- `.specify/` - Specification and planning tools
- `backend/` - FastAPI backend application
- `frontend/` - Next.js frontend application  
- `services/` - Additional services (notification, recurring)
- `dapr/` - Dapr components configuration
- `k8s/` - Kubernetes deployment manifests
- `helm/` - Helm charts
- `specs/` - API specifications and contracts
- `history/` - Prompt history records
- `todo-chatbot/` - Todo chatbot Helm chart

## Purpose
This structure organizes the complete application stack for the hackathon project.
